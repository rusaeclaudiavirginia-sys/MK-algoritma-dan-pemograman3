📊 Perbandingan Metode Pencarian

Linear Search

Pencarian dilakukan satu per satu mulai dari data pertama sampai data yang dicari ditemukan.

Kelebihan: sederhana dan tidak membutuhkan data terurut.

Binary Search

Pencarian dilakukan dengan membagi data menjadi dua bagian secara berulang sampai data ditemukan.

Syarat: data harus sudah terurut.
