📖 Pembahasan Bubble Sort

1. Pengertian Bubble Sort

Bubble Sort adalah algoritma pengurutan data dengan cara membandingkan dua elemen yang berdekatan. Jika urutannya tidak sesuai, kedua elemen akan ditukar sampai data tersusun sesuai urutan yang diinginkan.

2. Ascending

Ascending merupakan pengurutan data dari nilai terkecil hingga terbesar. Pada program ini, nilai mahasiswa diurutkan mulai dari nilai terendah sampai nilai tertinggi.

3. Descending

Descending merupakan pengurutan data dari nilai terbesar hingga terkecil. Pada program ini, mahasiswa dengan nilai tertinggi akan ditampilkan terlebih dahulu.

4. Cara Kerja Program

Program membandingkan nilai mahasiswa yang berdekatan. Apabila urutannya tidak sesuai dengan metode yang dipilih, kedua nilai ditukar. Proses perbandingan dilakukan berulang hingga seluruh data terurut. Setelah itu, tabel dan grafik diperbarui sesuai urutan terbaru.

5. Kesimpulan

Algoritma Bubble Sort dapat digunakan untuk mengurutkan nilai mahasiswa secara Ascending maupun Descending. Tampilan tabel dan grafik batang membantu pengguna memahami hasil pengurutan dengan lebih mudah.
